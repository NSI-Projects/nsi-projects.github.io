# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please follow these steps:

1. **Do not create a public issue.**  
   Security issues should be reported privately.

2. **Contact the project maintainers** via email:  
   `nsi.projects.contact@gmail.com`  

3. **Provide detailed information**:
   - Steps to reproduce the issue
   - Expected vs. actual behavior
   - Environment details (OS, Python version, browser, etc.)
   - Any relevant logs or screenshots

4. **Wait for a response**:  
   The maintainers will acknowledge your report and provide guidance.

---

## Reporting Guidelines

- Only report **valid security issues**.  
- For general questions or feature requests, use the public issue tracker.

## Acknowledgments

We appreciate responsible disclosure. Your help keeps this project safe for everyone 🐢.
